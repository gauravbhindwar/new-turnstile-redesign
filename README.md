# new-turnstile-redesign

Modern redesign of [turnstile.in](https://www.turnstile.in/) — Shield Automations' pedestrian & vehicle access-control website.

## Stack
- Semantic HTML5
- Custom CSS (no frameworks)
- Vanilla JavaScript interactions
- Zero dependencies

## Features
- Cinematic hero slider with animated headline rotator
- Filterable 13-category product showcase
- IWA 14-1 crash-test highlight band
- News & events section
- Dual-office contact section with validated enquiry form
- Scroll-reveal animations, scroll-spy nav, mobile menu
- Fully responsive, accessible, reduced-motion friendly

## Structure
```
turnstile-redesign/
├── index.html
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── img/          # images extracted from original site
```
